About

FASTAptamer 3.0: An End-to-End Platform for Bioinformatic Analysis of Nucleic Acid and Protein Combinatorial Selections.

System Overview

Preprocess Trim constant regions, filter by length, and remove low-quality reads from raw FASTQ files. Count Count and normalize unique sequences from a FASTA file, with optional reverse complement handling. Translate Translate nucleotide sequences to amino acids using standard or custom genetic codes. Motif Search, omit, track, and discover sequence motifs across nucleotide and amino acid sequences. Cluster Group sequences by Levenshtein edit distance, perform multiple sequence alignment, and analyze diversity. Sequence Enrichment Calculate enrichment scores by comparing sequence counts across two SELEX rounds. Distance Compute pairwise sequence distances and rank sequences by similarity to a query. Mutation Network Build and visualize mutational pathways between sequences within a defined edit distance. Pipeline Chain multiple tools into an automated sequential workflow and run them in one click.
