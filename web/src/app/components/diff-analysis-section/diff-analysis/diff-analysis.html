Performs differential expression analysis between two experimental conditions (each with at least one counted FASTA files). Sequences are compared using statistics: log₂FC log₂ fold change between conditions; log₂CPM log₂ of average counts per million across all replicates from both conditions combined — a measure of overall abundance, not a comparison between conditions; PValue — Benjamini-Hochberg FDR-adjusted p-value, which accounts for testing thousands of sequences simultaneously and is therefore more conservative than a standard p-value. A value of 0.05 means there is a 5% chance the observed difference is due to random variation; values closer to 0 indicate stronger evidence of a real difference between conditions. Requires ≥ 3 replicates per condition — otherwise shown as -. Sequences are classified as significant by the |log₂FC| and log₂CPM cutoffs; the adjusted p-value cutoff is optional and only applies when ≥ 3 replicates per condition are provided.
